Top-down to Bottom-up

Как мы говорили в предыдущей главе, обычно алгоритм «сверху вниз» реализовать проще, чем эквивалентный алгоритм «снизу вверх». С учетом вышесказанного полезно знать, как взять готовый нисходящий алгоритм и преобразовать его в восходящий. Для этого есть ряд причин: во-первых, если на собеседовании вы решаете задачу нисходящим способом, вас могут попросить переписать решение итеративным способом (используя восходящий метод). Во-вторых, как мы упоминали ранее, с точки зрения времени выполнения восходящий подход обычно более эффективен, чем нисходящий.

Шаги по преобразованию «сверху вниз» в «снизу вверх»

  1. Начните с завершенной реализации сверху вниз.
  2. Инициализировать массив dp, размер которого соответствует вашим переменным состояния. Например, предположим, что входными данными для задачи был массив числа и целое число k, который представляет максимальное количество разрешенных действий. Ваш массив dp будет 2D с одним измерением длины nums.length и другой длины к. Значения должны быть инициализированы как некоторые значения по умолчанию, противоположные тем, которые запрашивает проблема. Например, если проблема заключается в том, чтобы получить максимум чего-либо, установите значения на отрицательную бесконечность. Если он запрашивает минимум чего-либо, установите значения на бесконечность.
  3. Установите базовые варианты, такие же, как те, которые вы используете в своей нисходящей функции. Вспомните «Грабителя дома», dp(0) = nums[0] and dp(1) = max(nums[0], nums[1]). In bottom-up, dp[0] = nums[0] and dp[1] = max(nums[0], nums[1]).
  4. Напишите цикл for, который перебирает переменные вашего состояния. Если у вас есть несколько переменных состояния, вам понадобятся вложенные циклы for. Эти циклы должны начинаться с базовых случаев.
  5. Теперь каждая итерация самого внутреннего цикла представляет заданное состояние и эквивалентна вызову функции для того же состояния сверху вниз. Скопируйте логику вашей функции в цикл for и измените вызовы функций на доступ к вашему массиву. Все dp(...) меняется на dp[...].
  6. Сделано! dp теперь представляет собой массив, заполненный ответом на исходную задачу для всех возможных состояний. Верните ответ на исходную задачу, изменив return dp(...) в return dp[...].

Давайте попробуем быстрый пример с использованием предыдущего кода House Robber. Вот законченное решение сверху вниз:

def dp(i: int) -> int:

# Base cases

if i == 0:

return nums[0]

elif i == 1:

return max(nums[0], nums[1])


if i not in memo:

# Use recurrence relation to calculate dp[i].

memo[i] = max(dp(i - 1), dp(i - 2) + nums[i])


return memo[i]


memo = {}

return dp(len(nums) - 1)

Сначала мы инициализируем массив dp, размер которого соответствует нашим переменным состояния. Наша единственная переменная состояния — это i, который может взять n значений.

def rob(self, nums: List[int]) -> int:

n = len(nums)

dp = [0] * n


return dp[n - 1]

Во-вторых, мы должны установить наши базовые варианты. dp[0] = nums[0] и dp[1] = max(nums[0], nums[1]). Чтобы избежать выхода индекса за пределы, нам также следует просто вернуть nums[0], если есть только один дом.
