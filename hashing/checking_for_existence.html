Checking for existence

Одним из наиболее распространенных применений хеш-таблицы или набора является определение существования элемента в О(1). Поскольку массив нуждается O(n) для этого использование хэш-карты или набора может значительно улучшить временную сложность алгоритма, обычно с O(n2) до O(n). Давайте рассмотрим некоторые примеры задач.

Example 1: 1. Two Sum

Учитывая массив целых чисел nums и целочисленную target, верните индексы двух чисел так, чтобы их сумма составляла target. Вы не можете использовать один и тот же индекс дважды.

Решением грубой силы было бы использование вложенного цикла for для перебора каждой пары индексов и проверки, равна ли сумма целевому target. Это приведет к временной сложности O(n2). В решении методом грубой силы первый цикл for фокусируется на числе num, а второй цикл for ищет target — num в массиве. С помощью массива ищем target - num равно O(n), но с хеш-картой это О(1).

Мы можем построить хэш-карту, проходя по массиву, сопоставляя каждое значение с его индексом. По каждому индексу i, где num = nums[i], мы можем проверить нашу хэш-карту на предмет target — num. Добавление пар ключ-значение и проверка target — num все это O(1), поэтому наша временная сложность улучшится до O(n).

Нажмите для подробного объяснения

Мы ищем два числа, сумма которых соответствует target. Мы перебираем входные данные и для каждого элемента num смотрим, можно ли соединить этот элемент с другим числом, чтобы сформировать target.

Если существует другой элемент target — num, то их сумма num + target — num = target — это то, что мы ищем.

Поэтому, перебирая входные данные, мы помещаем элементы в хеш-карту. Затем в будущем мы сможем проверить, видели ли мы target-num для каждого num в О(1). Задача состоит в том, чтобы мы возвращали индексы вместо самих чисел, чтобы мы могли связать каждое число с его индексом.

def twoSum(nums: List[int], target: int) -> List[int]:

dic = {}

for i in range(len(nums)):

num = nums[i]

complement = target - num

if complement in dic: # This operation is O(1)!

return [i, dic[complement]]


dic[num] = i


return [-1, -1]

Если бы вопрос требовал, чтобы мы вернули логическое значение, указывающее, существует ли пара, или вернули сами числа, тогда мы могли бы просто использовать набор. Однако, поскольку ему нужны индексы чисел, нам нужно использовать хеш-карту, чтобы «запомнить», под какими индексами находятся числа.

Временная сложность равна O(n), поскольку операции хеш-карты О(1). В этом решении также используется Пространство O(n) как количество ключей, которые хеш-карта будет хранить, масштабируется линейно в зависимости от входного размера.

Example 2: 2351. First Letter to Appear Twice

Учитывая строку s, верните первый символ, который встретится дважды. Гарантируется, что ввод будет иметь повторяющийся символ.

Решением грубой силы было бы выполнить итерацию по строке и для каждого символа c повторить снова до c, чтобы увидеть, есть ли какое-либо совпадение.

def repeatedCharacter(s: str) -> str:

for i in range(len(s)):

c = s[i]

for j in range(i):

if s[j] == c:

return c


return ""

Это O(n2) из-за вложенного цикла. Второй цикл проверяет существование c, что можно сделать в O(1) с использованием набора.

def repeatedCharacter(s: str) -> str:

seen = set()

for c in s:

if c in seen:

return c

seen.add(c)


return " "

Это улучшает нашу временную сложность до O(n), поскольку каждая итерация цикла for теперь выполняется за постоянное время.

Пространственная сложность — более интересная тема для обсуждения. Многие люди будут утверждать, что сложность пространства O(1), поскольку входные данные могут содержать только символы английского алфавита, который ограничен константой (26). Это очень часто встречается при проблемах со строками и технически правильно. В условиях собеседования это, вероятно, безопасный ответ, но вы также должны отметить, что пространственная сложность может быть О(м), где m — количество допустимых символов во входных данных. Это более общий ответ, а также технически правильный.

Пример 3. Учитывая целочисленный массив nums, найдите все уникальные числа x в nums, которые удовлетворяют следующему: x + 1 не находится в nums, и x - 1 не находится в nums.

Мы можем решить эту проблему простым способом — просто перебираем nums и проверяем, находится ли x + 1 или x - 1 в nums. Если заранее преобразовать nums в набор, эти проверки будут стоить О(1).

Предварительное преобразование входных данных в набор — еще один пример предварительной обработки.

def find_numbers(nums):

ans = []

nums = set(nums)


for num in nums:

if (num + 1 not in nums) and (num - 1 not in nums):

ans.append(num)


return ans

Поскольку проверки занимают O(1), временная сложность равна O(n), поскольку каждая итерация цикла for выполняется за постоянное время. Набор займет O(n) пространство.
