Difference array

Разностные массивы не очень распространены, но их полезно иметь под рукой, потому что на собеседовании будет сложно сразу понять идею.

Массивы разностей используются, когда у вас есть проблема, связанная с интервалами событий. Вы можете думать о событиях, происходящих вдоль числовой прямой. Эта числовая линия может обозначать время или положение. События происходят на этой числовой прямой, имеющей начальную и конечную точку.

На входе будет либо 2D-массив, где каждый внутренний массив имеет формат [left, right, value], либо какая-либо эквивалентная форма. История проблемы обычно сводится к чему-то вроде «между left и right есть что-то value. Давайте посмотрим на несколько примеров.

Example 1: 1094. Car Pooling

В автомобиле есть место для capacity пассажиров и предусмотрен список trips. Каждая поездка представлена как [numPassengers, from, to], что означает, что в точке from она забирает numPassengers, а затем выгружает их в to. Может ли он совершить все рейсы, не вмещая в любой момент больше пассажиров, чем capacity?

В этой задаче числовая прямая — это дорога. Каждая поездка является событием и отображается на числовой строке в месте from и оставляет числовую строку в месте to. Во время мероприятия в машине находится numPassengers. Что касается формата ввода, о котором мы упоминали выше, у нас есть значение from as left, to as right и numPassengers as value.

Что мы можем сделать, так это построить числовую линию с помощью массива. Во-первых, нам нужно найти максимальное значение to, назовем его farthest. Затем мы можем инициализировать дорогу как массив arr с длиной farthest + 1.

Теперь для каждого события мы знаем, что numPassengers входят в машину в указанном from. Таким образом, мы можем выполнить arr[from] += numPassengers. В месте to numPassengers покинет машину, поэтому мы можем выполнить arr[to] -= numPassengers.

После обработки всех событий значения arr будут указывать изменение количества пассажиров на каждой позиции. Теперь мы можем просто рассчитать сумму префикса на дороге и проверить, превышает ли в какой-либо момент количество пассажиров (сумма префикса) capacity.

def carPooling(trips: List[List[int]], capacity: int) -> bool:

arr = [0] * (max(trip[2] for trip in trips) + 1)

for (value, left, right) in trips:

arr[left] += value

arr[right] -= value


curr = 0

for i in range(len(arr)):

curr += arr[i]

if curr > capacity:

return False


return True

Этот алгоритм дает нам временную и пространственную сложность O(n+m), где m = max(trip[2] for trip in trips). Без этого метода нам пришлось бы сортировать trips, что дало бы временную сложность О(n⋅logn).

Метод массива разностей строит этот массив, представляющий изменение количества пассажиров в каждой позиции, а затем использует сумму префикса.

Выше мы говорили, что формат ввода должен быть [left, right, value] или эквивалентная форма. Что подразумевается под эквивалентной формой?

Пример 2. Вы находитесь на улице с уличными фонарями, представленными массивом lights. Каждый источник света задается как [position, radius], что означает, что источник света расположен в определенной position и светит влево и вправо на расстоянии radius. Допустим, самое яркое место на улице — это место, где светится больше всего огней. Верните любую такую позицию.

Обратите внимание, что улица очень длинная — position <= 10^18.

Вот пример эквивалентной формы. В задаче не упоминается, что источники света имеют разную яркость, поэтому value = 1 для всех источников света. left можно рассчитать как position - radius, а right можно рассчитать как position + radius.

Поскольку в задаче упоминается, что улица очень длинная, было бы слишком дорого использовать тот же метод, что и в первом примере, где мы «строим» улицу, а затем идем по ней. Вместо этого мы можем создать массив change, где каждый элемент имеет значение [position, value], указывая, что яркость изменяется на value в position. Логика здесь идентична оригинальному методу — когда мы вводим освещение left, яркость увеличивается на value. Когда мы выходим из зоны освещения right, яркость уменьшается на value. Затем мы можем отсортировать массив и пройти по нему с помощью префиксной суммы.

def find_brightest_position(lights: List[List[int]]) -> int:

change = []

for position, radius in lights:

change.append([position - radius, 1])

change.append([position + radius + 1, -1])


change.sort()

ans = curr = brightest = 0

for position, value in change:

curr += value

if curr > brightest:

brightest = curr

ans = position


return ans

Как упоминалось в первом примере, при сортировке временная сложность становится О(n⋅logn). Это было необходимо, потому что улица очень длинная — использование первого метода было бы слишком медленным, поскольку position может быть до 1018.

Важно понимать, когда использовать первый или второй подход к методу. Логика «прогулки» очень похожа — отличается только часть «строительства», и правильное решение будет зависеть от ограничений задачи.
