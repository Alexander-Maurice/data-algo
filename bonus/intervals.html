Intervals

Другая распространенная закономерность — проблемы, связанные с интервалами [начало, конец]. Обычно эти проблемы можно решить, сначала отсортировав входные данные, а затем пройдя по ним и сравнивая соседние интервалы. Давайте посмотрим на несколько примеров.

Example 1: 252. Meeting Rooms

Дан массив intervals времени встреч, где intervals[i] = [start, end] указывает, что i-я встреча начинается с [start, end], определить, может ли один человек присутствовать на всех встречах.

Например, для заданных интервалов = [[0, 30], [5, 10], [15, 20]] возвращается false. Если вы посетите встречу [0, 30], то вы не сможете присутствовать на двух других.

Подход «грубой силы» заключался бы в том, чтобы просмотреть каждую пару встреч и проверить, нет ли совпадений, что потребовало бы O(n2), где n — количество встреч. Мы можем улучшить эту ситуацию, заметив, что в случае конфликта конфликтующие встречи будут соседними, если мы отсортируем входные данные.

Если мы отсортируем встречи по времени их начала, то встречи будут расположены в том порядке, в котором их следует посещать. Если i-я встреча начинается до конца (i - 1)th встречи, то возникает конфликт, потому что вам придется покинуть (i - 1)th встречи пораньше, чтобы успеть на ith встречи.

def canAttendMeetings(intervals):

intervals.sort()

for i in range(1, len(intervals)):

if intervals[i][0] < intervals[i - 1][1]:

return False


return True

Из-за сортировки временная сложность этого алгоритма равна О(n⋅logn). Это всё равно намного лучше, чем грубая сила О(п2). Объем используемого пространства зависит от используемого языка. Например, Python реализует временную сортировку, которая использует до O(n) пространство, но язык, использующий быструю сортировку, использует O(log) пространство.

Example 2: 56. Merge Intervals

Учитывая массив интервалов, где intervals[i] = [start, end], объедините все перекрывающиеся интервалы и верните массив непересекающихся интервалов, охватывающих все интервалы во входных данных.

Например, заданные intervals = [[1, 3], [2, 6], [8, 10], [15, 18]], верните [[[1, 6], [8, 10], [15, 18]]]. Первые два интервала сливаются, образуя [1, 6], а затем следующие два интервала не перекрываются.

В предыдущей задаче мы отсортировали интервалы по времени их начала, а затем сравнили соседние интервалы, чтобы проверить на перекрытие. Мы можем использовать тот же процесс здесь. Допустим, у нас есть два перекрывающихся интервала — [a, b] и [c, d]. Объединенный интервал должен быть [min(a, c), max(b, d)].

Давайте отсортируем входные данные по времени начала и построим массив ans по одному интервалу за раз. Если в любом заданном интервале мы обнаружим, что start меньше или равно времени окончания предыдущего интервала, это означает перекрытие, и мы должны объединить интервалы. Поскольку мы сортируем по времени начала, start предыдущего интервала всегда будет меньше, поэтому мы можем игнорировать часть min(a, c) из предыдущего абзаца. Нам просто нужно изменить новый конец с помощью max(b, d).

def merge(intervals: List[List[int]]) -> List[List[int]]:

intervals.sort()

ans = []


for start, end in intervals:

if ans and start <= ans[-1][1]:

ans[-1][1] = max(ans[-1][1], end)

else:

ans.append([start, end])


return ans

Как и в предыдущем примере, стоимость сортировки O(n⋅logn), где n — количество интервалов. Если мы не считаем ответ дополнительным пространством, то этот алгоритм использует то же пространство, что и предыдущий, что зависит от реализации сортировки.
