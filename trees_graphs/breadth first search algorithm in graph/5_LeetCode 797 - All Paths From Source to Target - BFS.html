Уточняющие примечания

Обратите внимание, что в момент 0:42 наш граф содержит только направленные ребра и в графе нет циклов. Это означает, что наш граф представляет собой ориентированный ациклический граф (DAG). Как указано в описании проблемы, гарантированно, что наши входные данные будут DAG. На момент 3:25 в видео упоминается, что нам не нужно записывать, какие узлы были посещены. Это потому, что наш данный граф является ориентированным ациклическим графом. Тот факт, что граф гарантированно является ациклическим, является небольшим, но важным отличием, которое позволяет нам не отслеживать, какие узлы были посещены.

Implementation

def allPathsSourceTarget(self, graph: List[List[int]]) -> List[List[int]]:

paths = []

if not graph or len(graph) == 0:

return paths


queue = deque()

path = [0]

queue.append(path)


while queue:

current_path = queue.popleft()

node = current_path[-1]

for next_node in graph[node]:

temp_path = current_path.copy()

temp_path.append(next_node)


if next_node == len(graph) - 1:

paths.append(temp_path)

else:

queue.append(temp_path)

return paths

Complexity Analysis

  • Временная сложность: О(2V ⋅V). Здесь, V представляет количество вершин.
    • Для графика с V вершин может быть не более 2V-1 −1 возможных путей от начальной вершины до целевой вершины. Нам нужно Время O(V) на построение каждого такого пути.
    • Таким образом, неопределенная верхняя граница временной сложности будет равна (2V-1 - 1) * O(V) = O(2V * V)
    • Поскольку у нас есть перекрытие между путями, реальное время, затраченное на обход, будет в некоторой степени ниже.
  • Пространственная сложность: О(2V ⋅V). Очередь может содержать О(2V ) путей, и каждый путь займет O(V) пространство. Следовательно, общая пространственная сложность равна О(2V ⋅V).
