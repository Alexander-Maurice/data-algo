LeetCode 1971 - Find if Path Exists in Graph - BFS

Video Solution

В этом видеорешении мы будем использовать подход BFS для решения проблемы определения существования пути от исходной вершины к целевой вершине в неориентированном графе.

Implementation

def validPath(n: int, edges: List[List[int]], start: int, end: int) -> bool:

adjacency_list = [[] for _ in range(n)]

for a, b in edges:

adjacency_list[a].append(b)

adjacency_list[b].append(a)


queue = collections.deque([start])

seen = set([start])


while queue:

# Get the current node.

node = queue.popleft()


# Check if we have reached the target node.

if node == end:

return True


# Add all neighbors to the queue.

for neighbor in adjacency_list[node]:

# Check if neighbor has been added to the queue before.

if neighbor not in seen:

seen.add(neighbor)

queue.append(neighbor)


# Our queue is empty and we did not reach the end node.

return False

Complexity Analysis

  • Временная сложность: О(В+Е). Здесь, V представляет количество вершин и E представляет количество ребер.
    • Чтобы создать список смежности, мы должны перебрать каждый из Е-края.
    • В цикле while мы посетим вершину максимум один раз.
    • Цикл for внутри цикла while будет иметь совокупную сумму не более E итераций, поскольку он будет перебирать всех соседей узла для каждого узла.
  • Пространственная сложность: О(В+Е).
    • Список смежности будет содержать O(V+E) элементов.
    • Очередь также будет содержать O(V) элементы.
    • Видимый набор будет использовать O(V) пространство для хранения посещенных узлов.
