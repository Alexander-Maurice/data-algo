LeetCode 797 - All Paths From Source to Target - DFS

Video Solution

В этом видеорешении мы решим задачу поиска всех путей от исходной вершины до целевой вершины в ориентированном ациклическом графе (DAG) с использованием подхода DFS. В качестве примера мы возьмем задачу «Все пути от источника к цели».

Уточняющие примечания

Обратите внимание на момент времени 1:02, что наш граф содержит только направленные ребра и в графе нет циклов. Это означает, что наш граф представляет собой ориентированный ациклический граф (DAG). Как указано в описании проблемы, гарантированно, что наши входные данные будут DAG. Сразу после 3:28 в видео упоминается, что нам не нужно записывать, какие узлы были посещены. Это потому, что наш данный граф является ориентированным ациклическим графом. Тот факт, что граф гарантированно является ациклическим, является небольшим, но важным отличием, которое позволяет нам не отслеживать, какие узлы были посещены.

Implementation

def allPathsSourceTarget(self, graph: List[List[int]]) -> List[List[int]]:

def dfs(node):

path.append(node)

if node == len(graph) - 1:

paths.append(path.copy())

return


next_nodes = graph[node]

for next_node in next_nodes:

dfs(next_node)

path.pop()


paths = []

path = []

if not graph or len(graph) == 0:

return paths

dfs(0)

return paths

Complexity Analysis

  • Временная сложность: О(2V ⋅V). Здесь, V представляет количество вершин.
    • Для ориентированного ациклического графа (DAG) с V вершин может быть не более 2V-1 - 1 возможных путей от начальной вершины до целевой вершины. Нам нужно Время O(V) на построение каждого такого пути.
    • Таким образом, неопределенная верхняя граница временной сложности будет равна (2V-1 - 1) * O(V) = O(2V * V)
    • Поскольку у нас есть перекрытие между путями, реальное время, затрачиваемое на обход, будет в некоторой степени ниже.
  • Космическая сложность: О(В). Глубина рекурсии не может превышать V., и нам нужно Пространство O(V) для хранения всех ранее посещенных вершин при рекурсивном перемещении глубже по текущему пути. Обратите внимание, что мы не учитываем использование пространства для вывода, т. е. для хранения всех полученных нами путей.
