Complexity Analysis

Временная сложность: O((V−1))!) Приведенный выше пример относится к неориентированному графу. Наихудший сценарий при попытке найти все пути — это полный граф. Полный граф — это граф, в котором каждая вершина соединена с каждой другой вершиной.

В полном графе будет V-1 уникальных путей длиной один, начинающихся в исходной вершине; один из этих путей пойдет к цели и закончится. Каждый из оставшихся путей будет иметь V−2 уникальных путей, исходящих из нее (поскольку ни один из них не вернется к исходной вершине, которая уже была посещена). Этот процесс будет продолжаться и приведет примерно к (V-1)! суммарные пути. Помните: как только путь достигает целевой вершины, он заканчивается, поэтому общее количество путей будет меньше (V-1)!.

Точное общее количество путей в наихудшем сценарии эквивалентно количеству расположений подмножества вершин, исключая исходный и целевой узел, что равно е⋅(V−2)!.

Находя все пути, на каждой итерации мы добавляем в стек все допустимые пути из текущей вершины, как показано на видео. Каждый раз, когда мы добавляем путь в стек, требуется Время O(V) для создания копии текущего пути, добавления к ней вершины и помещения ее в стек. Поскольку путь каждый раз увеличивается на одну вершину, путь длиной V должно быть скопировано и помещено в стек. V раз, прежде чем достигнет текущей длины. Поэтому интуитивно понятно, что каждый путь должен требовать О (V2 ) общее время. Однако в нашей логике есть изъян. Рассмотрим пример выше; в 2:50 добавляем в стек ADE. Затем в 3:20 мы добавляем в стек ADEC, ADEB и ADEF. ADE — это подпуть ADEC, ADEB и ADEF, но ADE создавался только один раз. Таким образом, время, необходимое для каждого пути создания ADE, можно представить как O(V), разделенное на количество путей, исходящих из ADE. Учитывая это, время, затрачиваемое на создание пути, равно В плюс V-1, разделенное на количество путей, исходящих из этого подпути, плюс V−2 раза... Для полного графа со многими узлами это в среднем составляет O(2⋅V)=O(V) время на путь.

Таким образом, временная сложность поиска всех путей в неориентированном графе в худшем случае равна количеству найденных путей. В O((V−2)) раз среднее время поиска пути O(V), что упрощается до О((V−1)!).
