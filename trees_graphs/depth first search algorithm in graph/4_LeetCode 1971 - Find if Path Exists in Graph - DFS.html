LeetCode 1971 - Find if Path Exists in Graph - DFS

Video Solution

В этом видеорешении мы будем использовать подход DFS для решения проблемы определения существования пути от исходной вершины к целевой вершине в неориентированном графе.

Implementation

class Solution:

def validPath(self, n: int, edges: List[List[int]], start: int, end: int) -> bool:


adjacency_list = [[] for _ in range(n)]

for a, b in edges:

adjacency_list[a].append(b)

adjacency_list[b].append(a)


stack = [start]

seen = set()


while stack:

# Get the current node.

node = stack.pop()


# Check if we have reached the target node.

if node == end:

return True


# Check if we've already visited this node.

if node in seen:

continue

seen.add(node)


# Add all neighbors to the stack.

for neighbor in adjacency_list[node]:

stack.append(neighbor)


# Our stack is empty and we did not reach the end node.

return False

Complexity Analysis

  • Временная сложность: О(В+Е). Здесь, V представляет количество вершин, а E представляет количество ребер.
    • Чтобы создать список смежности, мы должны перебрать каждый из Е-края.
    • В цикле while мы посетим вершину максимум один раз.
    • Цикл for внутри цикла while будет иметь совокупную сумму не более E итераций, поскольку он будет перебирать всех соседей узла для каждого узла.
  • Пространственная сложность: О(В+Е).
    • Список смежности будет содержать O(V+E) элементов.
    • Стек также будет содержать О(Е) элементов. Однако это можно свести к O(V), проверяя, был ли замечен neighbor узел, прежде чем добавлять его в стек.
    • seen набор будет использовать O(V) пространство для хранения посещенных узлов.
