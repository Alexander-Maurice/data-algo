Quick Find - Disjoint Set

Explanation of Quick Find

В этом видео мы поговорим о реализации быстрого поиска непересекающегося набора и рассмотрим две его основные операции, а также их сложность: поиск и объединение.

Algorithm

Вот пример реализации быстрого поиска Disjoint Set.

# UnionFind class
class UnionFind:

def __init__(self, size):

self.root = [i for i in range(size)]


def find(self, x):

return self.root[x]


def union(self, x, y):

rootX = self.find(x)

rootY = self.find(y)

if rootX != rootY:

for i in range(len(self.root)):

if self.root[i] == rootY:

self.root[i] = rootX


def connected(self, x, y):

return self.find(x) == self.find(y)




# Test Case
uf = UnionFind(10)
# 1-2-5-6-7 3-8-9 4
uf.union(1, 2)
uf.union(2, 5)
uf.union(5, 6)
uf.union(6, 7)
uf.union(3, 8)
uf.union(8, 9)
print(uf.connected(1, 5)) # true
print(uf.connected(5, 7)) # true
print(uf.connected(4, 9)) # false
# 1-2-5-6-7 3-8-9-4
uf.union(9, 4)
print(uf.connected(4, 9)) # true

Time Complexity

Union-find Constructor Find Union Connected
Time Complexity O(N) O(1) O(N) O(1)

Примечание: N — количество вершин в графе.

  • При инициализации union-find constructor нам нужно создать массив размером N со значениями, равными соответствующим индексам массива; для этого требуется линейное время.
  • Каждый вызов для find потребует Время O(1), поскольку мы просто получаем доступ к элементу массива по заданному индексу.
  • Каждый вызов union потребует Время O(N), потому что нам нужно пройти через весь массив и обновить корневые вершины для всех вершин набора, который будет объединен с другим набором.
  • Connected операция занимает Время O(1), поскольку оно включает в себя два вызова поиска и операцию проверки равенства.
