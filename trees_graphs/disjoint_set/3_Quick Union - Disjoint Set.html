В 00:06 в функции объединения в коде Quick Union строка root[rootY] = x должна иметь вид root[rootY] = rootX, как показано в коде ниже.

Algorithm

Вот пример реализации быстрого объединения Disjoint Set.

# UnionFind class class UnionFind:

def __init__(self, size):

self.root = [i for i in range(size)]


def find(self, x):

while x != self.root[x]:

x = self.root[x]

return x


def union(self, x, y):

rootX = self.find(x)

rootY = self.find(y)

if rootX != rootY:

self.root[rootY] = rootX


def connected(self, x, y):

return self.find(x) == self.find(y)



# Test Case
uf = UnionFind(10)
# 1-2-5-6-7 3-8-9 4
uf.union(1, 2)
uf.union(2, 5)
uf.union(5, 6)
uf.union(6, 7)
uf.union(3, 8)
uf.union(8, 9)
print(uf.connected(1, 5)) # true
print(uf.connected(5, 7)) # true
print(uf.connected(4, 9)) # false
# 1-2-5-6-7 3-8-9-4
uf.union(9, 4)
print(uf.connected(4, 9)) # true

Time Complexity

Union-find Constructor Find Union Connected
Time Complexity O(N) O(N) O(N) O(N)

Примечание: N — количество вершин в графе. В худшем случае количество операций для получения корневой вершины составит H где H – высота дерева. Поскольку эта реализация не всегда указывает корень более короткого дерева на корень более высокого дерева, H может быть не более N, когда дерево образует связанный список.

  • Как и в реализации быстрого поиска, при инициализации union-find constructor нам нужно создать массив размером N со значениями, равными соответствующим индексам массива; для этого требуется линейное время.
  • Для операции find в худшем случае нам нужно пройти каждую вершину, чтобы найти корень входной вершины. Максимальное количество операций для получения корневой вершины будет не больше высоты дерева, поэтому потребуется O(n) время.
  • Операция union состоит из двух операций поиска, которые (только в худшем случае) будут принимать Время O(N) и две операции с постоянным временем, включая проверку равенства и обновление значения массива по заданному индексу. Следовательно, операция объединения также стоит O(N) в худшем случае.
  • Connected операция также занимает Время O(N) в худшем случае, поскольку оно включает два вызова find.
