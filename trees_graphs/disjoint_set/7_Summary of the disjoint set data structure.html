Summary of the “disjoint set” data structure

Основная идея «непересекающегося множества» состоит в том, чтобы все связанные вершины имели один и тот же родительский узел или корневой узел, независимо от того, связаны ли они напрямую или косвенно. Чтобы проверить, соединены ли две вершины, нам нужно только проверить, имеют ли они один и тот же корневой узел.

Двумя наиболее важными функциями для структуры данных «непересекающееся множество» являются функция find и функция union. Функция find находит корневой узел данной вершины. Функция union соединяет две ранее несвязанные вершины, присваивая им один и тот же корневой узел. Есть еще одна важная функция Connected, которая проверяет «связность» двух вершин. Функции find и union необходимы для любого вопроса, в котором используется структура данных «непересекающееся множество».

find function of the “disjoint set”

«Непересекающееся множество» в основном использует функцию find для поиска корневого узла данной вершины.

  • Базовая реализация функции find:
def find(self, x):

while x != self.root[x]:

x = self.root[x]

return x

  • Функция find, оптимизированная со сжатием пути:
def find(self, x):

if x == self.root[x]:

return x

self.root[x] = self.find(self.root[x])

return self.root[x]

union function of the “disjoint set”

«Непересекающееся множество» в основном использует функцию union для соединения двух вершин x и y путем приравнивания их корневого узла.

  • Базовая реализация функции union:
def union(self, x, y):

rootX = self.find(x)

rootY = self.find(y)

if rootX != rootY:

self.root[rootY] = rootX

  • Функция union – оптимизирована объединением по рангу:
def union(self, x, y):

rootX = self.find(x)

rootY = self.find(y)

if rootX != rootY:

if self.rank[rootX] > self.rank[rootY]:

self.root[rootY] = rootX

elif self.rank[rootX] < self.rank[rootY]:

self.root[rootX] = rootY

else:

self.root[rootY] = rootX

self.rank[rootX] += 1

connected function of the “disjoint set”

Функция Connected проверяет, соединены ли две вершины x и y, проверяя, имеют ли они один и тот же корневой узел. Если x и y имеют один и тот же корневой узел, они связаны. В противном случае они не связаны.

def connected(self, x, y):

return self.find(x) == self.find(y)
