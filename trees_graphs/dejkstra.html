Алгоритм Дейкстры простыми словами

Представь, что ты муравей, который стоит в одной точке лабиринта и хочет быстрее всего добраться до другой точки. Алгоритм Дейкстры помогает найти самый короткий путь.

Вот как он работает, как игра:

  • У каждой точки есть число — сколько шагов от начала до неё. Вначале у начала — 0, у всех остальных — «очень много» (бесконечность).
  • Смотрим на соседей из текущей точки. Если идти через текущую точку к соседу короче, чем было записано — запоминаем новый путь.
  • Отмечаем точку «посещённой» и больше её не трогаем.
  • Переходим в следующую точку с самым маленьким расстоянием, которую ещё не посетили.
  • Повторяем, пока не дойдём до цели (или не обойдём все точки).

Простой пример на Python

Представь карту: точки соединены дорогами (рёбрами) с разной длиной.

import heapq
def deikstra(graph, start, end):

# расстояние до каждой точки: сначала бесконечность

distances = {point: float('inf') for point in graph}

distances[start] = 0 # до старта 0 шагов


# очередь, где (расстояние, точка)

queue = [(0, start)]


while queue:

current_dist, current = heapq.heappop(queue) # берём точку с самым маленьким расстоянием


if current == end: # дошли до цели

return current_dist


if current_dist > distances[current]:

continue # устаревшая запись, пропускаем


# смотрим всех соседей

for neighbor, weight in graph[current].items():

distance = current_dist + weight

if distance < distances[neighbor]: # нашли путь короче?

distances[neighbor] = distance

heapq.heappush(queue, (distance, neighbor))


return distances[end]


# Карта: точка -> {сосед: вес}

graph = {

'A': {'B': 1, 'C': 4},

'B': {'A': 1, 'C': 2, 'D': 5},

'C': {'A': 4, 'B': 2, 'D': 1},

'D': {'B': 5, 'C': 1}

}


# Кратчайший путь от A до D

print(deikstra(graph, 'A', 'D')) # выведет 4 (A->B->C->D: 1+2+1=4)

Объяснение для ребёнка:

  • heapq — это как волшебная очередь, которая всегда даёт самую близкую необработанную точку.
  • float('inf') — так мы говорим: «до сюда путь бесконечно длинный, пока не нашли».
  • Алгоритм шаг за шагом улучшает известные расстояния, пока не найдёт самый короткий путь.

Этот алгоритм повсюду: в навигаторах, в компьютерных играх для поиска пути, в интернете для передачи данных по самым быстрым маршрутам.
