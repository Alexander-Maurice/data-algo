SELECT, INSERT, UPDATE and DELETE

Чему вы научитесь

  1. Базовый синтаксис о том, как читать, создавать, изменять и удалять данные.
  2. Основные изменения синтаксиса для реальных сценариев.

Те, кто знаком с системой программного обеспечения, также могут быть знакомы с четырьмя режимами работы с данными: создание, чтение, обновление и удаление (CRUD). Эти четыре поведения представляют собой самые основные операции; они также являются первым синтаксисом, который мы должны понять.

На более продвинутых стадиях синтаксиса SQL способы его использования в различных программах реляционных баз данных будут разными. Но для основных операций использование каждого программного обеспечения практически одинаково, просто немного отличается.

Basic syntax

Давайте сначала рассмотрим базовую структуру синтаксиса SQL:

SELECT `id`, `name` FROM `new_schema`.`users`;

Вы можете увидеть часть грамматики выше. SELECT и FROM — это ключевые слова в SQL, и мы обсудим, что они означают позже. Что касается других слов, используемых в середине, id и name — это имена столбцов, new_schema — это имя схемы, а users — это имя таблицы.

Sample data

Начнем с примера таблицы users, чтобы помочь вам понять, какие результаты будут представлены при выполнении оператора SQL.

CREATE SCHEMA `new_schema` DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

CREATE TABLE `new_schema`.`users` (
`id` INT NOT NULL AUTO_INCREMENT COMMENT 'This is the primary index',
`name` VARCHAR(45) NOT NULL DEFAULT 'N/A',
`age` INT NULL,
`height` INT NULL,
PRIMARY KEY (`id`)
);

Create data: INSERT

INSERT INTO `new_schema`.`users` (`id`, `name`, `age`) VALUES (4, 'Harry', 33);

Это запрос на добавление данных в базу данных. Здесь есть три ключевых слова:
1. INSERT INTO: эти два слова можно объединить и в основном используются для указания таблицы базы данных и добавляемых столбцов. Таким образом, этот оператор добавит одну новую запись в таблицу users и установит значение для id, name и age. Эти столбцы необходимо подготовить перед добавлением данных.
2. VALUES: добавляемое значение будет установлено после этого слова, и оно должно будет соответствовать столбцам, указанным после INSERT INTO. После выполнения запроса в базу данных будет вставлена запись с идентификатором, равным 4, имя Гарри, возраст 33 года.

При написании оператора вставки главное помнить, что имена и значения полей должны быть правильно сопоставлены друг с другом. Таким образом, оператор INSERT относительно прост по сравнению с оператором SELECT, который имеет другой, более сложный синтаксис, о котором мы познакомимся в последующих главах.

Create Multiple New Records

Чтобы добавить несколько записей, вы можете добавить новый набор данных непосредственно после VALUES. Вот пример:

INSERT INTO `new_schema`.`users` (`id`, `name`, `age`) VALUES (4, 'Harry', 33), (5, 'Tom', 30);

Результат:

id name age
1 John 50
2 May 40
3 Tim 10
4 Harry 33
5 Tom 30

Read Data: SELECT

Чтение данных — одно из наиболее распространенных применений SQL. Давайте посмотрим на пример кода:

SELECT `id`, `name` FROM `new_schema`.`users`;

Здесь есть два ключевых слова: SELECT и FROM:
1. FROM: Это слово относится к работе с какой таблицей и какой базой данных. В данном примере это относится к работе с таблицей пользователей в базе данных new_schema. 2. SELECT : это слово означает выбор столбцов для отображения. В этом примере в результате будут отображены столбцы идентификатора и имени.

Выполненный результат:

id name
1 John
2 May
3 Tim

Read All

Кроме того, многие разработчики предпочитают использовать в небольших проектах оператор SELECT следующим образом:

SELECT * FROM `new_schema`.`users`;

Использование звездочки ('*') вместо перечисления имен столбцов позволит получить все столбцы таблицы и получить следующий результат:

id name age
1 John 50
2 May 40
3 Tim 10

Это очень удобное утверждение, и вам не нужно специально перечислять все столбцы. Однако следует отметить, что если данные в таблице очень большие, производительность SELECT * может быть очень низкой.

Поэтому в более сложной и большой базе данных используйте SELECT * только после тщательного рассмотрения.

Conditions

Что касается того, как получить нужные данные в соответствии с условиями, вы можете обратиться к следующей главе, в которой более подробно обсуждается предложение WHERE. Здесь мы начнем с простого примера оператора и результата:

SELECT * FROM `new_schema`.`users` WHERE `id` = 2;
id name age
2 May 40

Как видите, результат показывает только те данные, где id равен 2.

В технической статье или разговоре оператор SQL будет называться «запросом». В дальнейшем мы можем использовать термин «запрос» при упоминании оператора SQL.

Modify Data: UPDATE

UPDATE `new_schema`.`users` SET `name` = 'Andy', `age` = 100 WHERE `id` = 2;

Есть два ключевых слова, на которых мы можем сосредоточиться:
1. UPDATE. После этого ключевого слова следует имя обновляемой таблицы.
2. SET: Ниже приведены значения, которые следует обновить в существующих данных. Если столбцов несколько, разделите их запятыми.

Мы часто используем ключевое слово WHERE для фильтрации данных. Хотя это необязательно и его не обязательно записывать, если его не добавить, оно станет полным обновлением таблицы, что является редкой ситуацией.

Существует также множество программ баз данных, которые по умолчанию имеют защиту для предотвращения таких опасных операций.

После завершения выполнения (с предложением WHERE) оно обновит только запись с идентификатором 2, установив имя Andy и возраст 100.

Результат:

id name age
1 John 50
2 Andy 100
3 Tim 10

Remove Data: DELETE

DELETE FROM `new_schema`.`users` WHERE `id` = 1;

Единственное новое ключевое слово здесь — DELETE. Он связан с FROM, ключевым словом, которое мы видели ранее и которое указывает на то, с какой таблицей работать.

Логика работы здесь аналогична UPDATE. WHERE можно добавлять или нет, но на практике удалить данные всей таблицы вряд ли получится. Поэтому нам обычно необходимо включать WHERE, чтобы ограничить диапазон удаляемых данных.

Результат:

id name age
2 May 40
3 Tim 10
