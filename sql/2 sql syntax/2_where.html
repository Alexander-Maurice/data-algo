WHERE

Чему вы научитесь

  1. Как запрашивать данные с отдельными и сравниваемыми условиями.
  2. Как запросить данные с условием диапазона.
  3. Как запросить данные с нечетким условием.

В предыдущем разделе мы представили предложение WHERE. Этот раздел предоставит вам дополнительную практику использования предложения WHERE и поможет вам научиться легко извлекать данные с использованием различных условий.

Sample data

Результаты поиска по всей главе будут ссылаться на этот пример набора данных:

id name age height
1 John 50 180
2 May 40 Null
3 Tim 10 170
4 Jay 20 155

Basic Conditions

Equal To, Greater Than, and Less Than

Начнем с рассмотрения примера простейшего использования WHERE и его результатов:

SELECT * FROM `new_schema`.`users` WHERE id = 1;
id name age height
1 John 50 180

Помимо символа = SQL также поддерживает символы «больше» и «меньше»:

SELECT * FROM `new_schema`.`users` WHERE id > 2;
id name age height
3 Tim 10 170
4 Jay 20 155
SELECT * FROM `new_schema`.`users` WHERE id <= 1;
id name age height
1 John 50 180

Предположим, вы хотите использовать отрицательное условие, которое не равно, тогда мы можем использовать !=:

SELECT * FROM `new_schema`.`users` WHERE id != 1;
id name age height
2 May 40 NULL
3 Tim 10 170
4 Jay 20 155

NULL

В SQL, если вы хотите определить, что значение в столбце равно NULL, его нельзя записать как columnA = NULL. Поскольку NULL — это специальное значение для базы данных, его нельзя использовать при общем сравнении значений. Вместо этого мы можем использовать следующее:

SELECT * FROM `new_schema`.`users` WHERE height IS NULL;
id name age height
2 May 40 NULL

Для противоположного условия вам нужно добавить еще одно ключевое слово NOT.

SELECT * FROM `new_schema`.`users` WHERE height IS NOT NULL;
id name age height
1 John 50 180
3 Tim 10 170
4 Jay 20 150

Multiple Conditions

В предыдущем разделе основное внимание уделялось оператору извлечения данных с использованием одного условия. Что нам делать, если мы хотим использовать несколько условий? В этой ситуации нам необходимо использовать логические операторы, то есть объединять ключевые слова AND и OR в операторах SQL для удовлетворения наших требований.

AND

SELECT * FROM `new_schema`.`users` WHERE age < 40 AND height> 160;
id name age height
3 Tim 10 170

В этом операторе ключевое слово AND используется для того, чтобы гарантировать, что каждая запись удовлетворяет как условию слева (age < 40), так и условию справа (height > 160).

OR

SELECT * FROM `new_schema`.`users` WHERE age < 40 OR height> 160;
170
id name age height
1 John 50 180
3 Tim 10
4 Jay 20 155

В этом запросе используется ключевое слово OR, чтобы гарантировать, что данные, соответствующие одному из условий (age < 40 слева или height > 60 справа), будут получены.

Обратите внимание на рекорд за May. Поскольку высота May равна NULL, в операции она не будет рассматриваться как пустое значение или 0. Это было бы напрямую исключено из результата!

AND + OR

SELECT * FROM `new_schema`.`users` WHERE id < 4 AND (age> 30 OR height > 175);
id name age height
1 John 50 180
2 May 40 NULL

Этот запрос более сложный, но распространен в реальном мире. Для формирования этого оператора SQL необходимо объединить несколько условий.

Поэтому вы можете использовать круглые скобки для разделения логических блоков, которые будут работать независимо. Если предположить, что круглые скобки отсутствуют, текущее состояние (age > 30 OR height > 175), которое можно было бы объединить и вычислить вместе, будет разобрано и обработано отдельно, что повлияет на окончательный результат данных.

Примечание. Вы можете обратиться к разделу «Приоритет операторов в MySQL», чтобы получить более подробную информацию о том, почему здесь важны круглые скобки.

Range Conditions

Запрос диапазона также является одним из распространенных типов проблем поиска данных. Три наиболее распространенных типа диапазонов в SQL — это IN, BETWEEN и LIKE.

IN

SELECT * FROM `new_schema`.`users` WHERE `id` IN (1, 3);
id name age height
1 John 50 180
3 Tim 10 170

Использование ключевого слова IN заставит SQL сравнивать только значение указанного столбца с абсолютной точностью, например, в этом случае будут выбраны только записи с идентификатором, равным 1 или 3.

Как и в предыдущем примере оператора IS NULL, вы можете добавить ключевое слово NOT перед IN, чтобы получить противоположный результат.

Например:

SELECT * FROM `new_schema`.`users` WHERE id NOT IN (1, 4);
id name age height
2 May 40 NULL
3 Tim 10 170

BETWEEN

SELECT * FROM `new_schema`.`users` WHERE height BETWEEN 160 AND 190;
id name age height
1 John 50 180
3 Tim 10 170

BETWEEN необходимо использовать с ключевым словом AND для получения данных в определенном диапазоне. Как и IN, существует режим обратного запроса с NOT.

LIKE

LIKE — мощное ключевое слово SQL, поддерживающее регулярные выражения, которые часто используются для сравнения текста во многих языках программирования.

Мы собираемся представить три наиболее часто используемых метода поиска и сравнения.

SELECT * FROM `new_schema`.`users` WHERE name LIKE '%a%';
id name age height
2 May 40 NULL
4 Jay 20 155

Логика сопоставления, используемая в этом предложении, заключается в поиске записей с именами, содержащими букву «а». Используйте два символа % (по одному с каждой стороны) и поместите слово, которое вы хотите найти, посередине.

Примечание. Знак процента (%) будет соответствовать нулю, одному или нескольким символам. Чтобы соответствовать только одному символу, мы могли бы использовать подчеркивание (_).
SELECT * FROM `new_schema`.`users` WHERE name LIKE 'J%';
id name age height
1 John 50 180
4 Jay 20 155

В дополнение к обычному режиму сравнения содержимого вы также можете использовать другой синтаксис для поиска данных, имя которых начинается с J. Этот подход заключается в том, чтобы оставить только символ % и поместить его в конец искомой строки.

Обратите внимание, что знак процента (%) является подстановочным знаком; он будет соответствовать нулю, одному или нескольким символам. Чтобы соответствовать только одному символу, мы могли бы использовать подчеркивание (_).

Итак, если вы хотите узнать данные, имя которых заканчивается на y, просто напишите:

SELECT * FROM `new_schema`.`users` WHERE name LIKE '%y';
id name age height
2 May 40 NULL
4 Jay 20 155
